# Hussain Muffallal - Personal Portfolio

A modern, high-performance personal portfolio and developer sandbox built with React, Vite, and Tailwind CSS. Designed to showcase progression across AI/ML engineering, full-stack development, and freelance client delivery.

![Portfolio Preview](/public/homepage.png) 

## 🏗 Architecture & Features

This platform abandons the traditional "endless scroll" template in favor of a curated, component-driven architecture:

*   **Three-Tier Project Narrative:** 
    *   *Tier 1 (Featured Engineering):* Deep-dive case studies for complex AI/ML architectures (e.g., EventLK).
    *   *Tier 2 (Client Projects):* High-level overviews of freelance deployments with live production links.
    *   *Tier 3 (Developer Archive):* A scannable data-table layout for academic and foundational GitHub repositories.
*   **Technical Arsenal Matrix:** A categorized, scannable grid of core competencies (Frontend, Backend, AI/ML, Database) combined with an active learning trajectory banner.
*   **Secure Contact Pipeline:** Integrated Web3Forms with a hidden honeypot implementation to block scraping bots and spam.
*   **Fully Responsive:** Fluid layouts built with Tailwind CSS, utilizing `aspect-video` and flex grids for seamless mobile-to-desktop scaling.

## 💻 Tech Stack

*   **Framework:** React 18 + Vite
*   **Styling:** Tailwind CSS
*   **Icons:** Lucide React & Custom inline SVGs
*   **Form Handling:** Web3Forms API
*   **Deployment:** Vercel (CI/CD Pipeline)

## 🚀 Local Development

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hussainmuffallal/hussain-muffallal-portfolio.git

2. **Navigate to the directory:**
    ```bash
    cd your-repo-name

3. **Install dependencies:**
    ```bash
    npm install

4. **Start the development server:**
    ```bash
    npm run dev

The site will be available at http://localhost:5173
